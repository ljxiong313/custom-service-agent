# 代码规范

适用对象：本项目全部前后端代码与后续生成的 Agent/协作者代码。目标是小团队可长期维护、
代码本身即文档。**注释使用中文**，解释「为什么」而非「是什么」。

## 后端（Python）

1. **版本与风格**：Python 3.12；全量 type hints；`from __future__ import annotations`；
   模块首部一句话 docstring 说明职责与关键设计决策。
   （唯一例外：`db/models.py` 禁用 PEP 56 惰性注解——SQLAlchemy 需运行时解析 Relationship。）
   SQLModel 有两处固定的类型代偿：列上的 `.desc()/.in_()/.like()/order_by()` 一律包
   `sqlmodel.col(...)`（裸属性在类型系统里是值类型，不是列）；取"已落库"行的自增主键
   一律走 `db.models.pk(row)`，不在调用点写 `# type: ignore` 或 `or 0` 兜底。
   `py -m mypy` 覆盖 `app/` 与 `eval/`，当前口径是 0 error——新增报错就地修，
   不放宽 error code、不关检查项。
2. **分层纪律**：见 docs/项目结构说明.md 的依赖规则。新增能力按
   `db/models → services → api/v1` 顺序落地，禁止 api 间互相 import。
3. **命名**：文件 snake_case；类 PascalCase；接口路径 RESTful 复数
   （`/conversations/{id}/messages`）；SQLModel 表名默认复数。
4. **配置**：一切可变参数进 YAML（config.simple.yaml 给默认值），代码里用
   `settings.get_dotted("a.b.c", 默认值)` 读取；禁止散落的 `os.environ`。
   端口/监听地址同样只有 `server.host`/`server.port` 一个来源，由 `run.py` 读取后交给
   uvicorn——不要在启动命令里另写一套，也不要给 run.py 加 `--reload`/`--workers`
   （多进程会复制 sweeper 与 MCP 确认表，见 app/main.py 的部署形态说明）。
5. **错误处理**：
   - 业务错误 → `HTTPException(4xx, 用户可读中文消息)`；
   - LLM 未配置 → `ModelNotConfiguredError`，在流开始前转 400；
   - SSE 流内部异常 → 下发 `error` 事件，不静默吞掉；
   - 禁止裸 `except: pass`。
6. **鉴权**：所有业务接口经 `CurrentUser` / `DbSession` 依赖（Annotated 别名复用）；
   用户侧资源访问必须校验归属（防 IDOR，参考 conversation._get_owned、handoff `/request` 只允许本人会话）；
   B1-7 起 `User.role` 只有 `admin`/`user` 两档，判据是"会不会改动全局语料、拉起本机进程、
   动别人账号"：MCP 服务器增删改与命令执行、知识库写操作、角色变更走 `RequireAdmin`；
   **运营台刻意放开**——`console.*` 跨用户只读/代答、工单跨用户接单属客服团队共用工作台，
   口径写在各模块 docstring 里。首个注册账号自动升 admin（否则空库自举时没人能配置），
   真正的客服分级（staff 表/组/权限位）仍未做，见 docs/待办与风险.md。
7. **数据库**：只用 `create_all`——它会建新表/新索引，但**不会 ALTER 已有列**；
   新增/改字段需删库重建或手工迁移（本项目未引入 Alembic）。删除关联数据显式处理
   （见删除会话级联删消息、`ingest.remove_file`/`ingest.purge`）。
8. **日志**：loguru；关键路径（登录、模型调用失败、后续转人工/回调）必须留痕；
   不打印密码、token、完整 api_key。
9. **依赖**：`requirements.txt` 每个包都带版本上界（>=1.0 的锁下一个主版本，0.x 的锁到
   当前验证过的次版本线）；直接 `import` 的包必须显式声明，不吃传递依赖。升级上界后跑
   `py -m pytest` + `scripts/smoke_test.py` 绿了才算完成。开发工具在 `requirements-dev.txt`。

## 前端（TypeScript / Vue3）

1. **只写 `<script setup lang="ts">`**；组件 PascalCase 文件名；页面在 `pages/`，
   可复用块在 `components/`。
2. **网络层收口**：所有请求走 `apis/http.ts`（自动带 token、401 登出、错误 toast），
   组件内禁止裸 `fetch`。P8 起界面没有 SSE 消费方——运营台靠 `stores/console.ts` 轮询
   刷新消息（后端的 SSE 端点保留，供评测/集成脚本使用），新增实时能力时再统一收口，
   不要在各页面各写一套定时器。
3. **时间显示**：只允许 `utils/time.ts` 的格式化函数（后端发的是 naive UTC ISO，
   页面自行 `new Date(iso)` 会整体偏 8 小时）。
4. **状态管理**：跨页面状态进 Pinia store；组件内部状态用 `ref/reactive`。
   store 用 setup 语法 + `persist` 白名单（只持久化必要字段）。
5. **样式**：颜色/圆角只允许引用 `styles/theme.css` 的 CSS 变量；
   组件样式一律 `scoped`；覆盖 Element Plus 用 `:deep()`。
6. **安全**：任何模型/用户输出注入 HTML 前必须过 DOMPurify（见 MessageList.renderMd）；
   token 存 localStorage 为演示方案，生产建议 httpOnly cookie（在 README 中声明）。
7. **类型**：接口返回结构在 `stores/` 或 `apis/` 中定义 interface 并导出复用；
   禁止 `any`（第三方事件除外，加注释豁免）。
8. **交互约定**：提交中用 `:loading`/`:disabled` 锁按钮，失败只由 http 层 toast 一次，
   组件不重复弹窗；列表/详情页必须渲染三态——`v-loading` 加载中、`el-empty` 空态、
   错误提示，不能拿空白页冒充"加载完了"；筛选后的空态要带上筛选条件本身
   （`「待接单」下暂无工单`），否则用户分不清"没数据"还是"筛选坏了"；可交互但非按钮的元素
   （会话列表拖拽分隔条、纯图标按钮）必须带 `aria-label` 且可键盘聚焦——**给了
   `role`/`tabindex` 就必须配真的键盘处理**，分隔条要响应 ←/→（B2-4 走查就是按这条抓出
   ChatView 的假可访问）；窄屏靠 `.shell-main` 的 `min-width: 0` 与内部横向滚动消化宽度，
   不挤压列宽、不做抽屉式导航；页面文案不得声称"存在内存/重启清空"——B1-2 起外发箱、
   入库任务、sweeper 状态都已落库，这类过期描述比没写更糟。

## 提交与验证

- 每个阶段（P0/P1/...）一个可运行闭环：后端接口 + 前端入口 + 手动验收路径。
- 仓库根目录的 `pyproject.toml` 是 pytest / ruff / mypy 三个工具共用的唯一配置，
  四条命令就是闸门，都从仓库根跑：

  ```bash
  py -m pytest                 # 离线单测，不需要后端在跑（testpaths 已限定，别手改收集范围）
  py -m ruff check src eval    # 只 check，不跑 ruff format——全量格式化会产生 60+ 文件的无关 diff
  py -m mypy                   # 覆盖 app/ 与 eval/，口径 0 error
  cd src/frontend && volta run npm run typecheck
  ```

- 端到端仍需真实服务：`scripts/smoke_test.py`（45 项）、`scripts/platform_smoke.py`（29 项）、
  `eval/run_eval.py`（9 项）；这三项会打模型，跑之前确认 `CS_CONFIG` 指向带 key 的配置。
  写 Chroma 的脚本（reindex/reingest）必须先停后端，两个进程同时开 PersistentClient 会坏。
- 未经用户要求不做 git commit；不提交 `config.local.yaml`、`data/`（备份快照在
  `data/backups/` 下，同样被 gitignore 挡住，里面含明文密钥，别单独拷出去）。
