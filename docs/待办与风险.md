## 一、部署与运行约束（刻意取舍，不是 bug）

1. **只能单进程、单副本**。会话生命周期扫描任务和 MCP 工具确认表都是进程内状态：
   多 worker 会各扫一遍（重复结束提示、重复强制结单），确认请求还可能落到没有那个
   future 的进程上必然超时。检测与告警在 [app/main.py:48-51](file:///F:/WWW/AI/AgentCustomService/src/backend/app/main.py#L48)，
   确认表在 [app/services/mcp/confirm.py:49-60](file:///F:/WWW/AI/AgentCustomService/src/backend/app/services/mcp/confirm.py#L49)。
   *要水平扩展必须先做这两件事*：确认请求/结果落库（改为轮询式状态机）+ sweeper 选主。
2. **记忆管道重启即丢**。[app/services/memory/pipeline.py:1-5](file:///F:/WWW/AI/AgentCustomService/src/backend/app/services/memory/pipeline.py#L1)
   用 `asyncio.create_task` 挂后台，进程在摘要/画像抽取中途退出不会补跑（当轮对话不受影响，
   记忆是增强项）。要可靠需把任务落库（参照 `knowledge_jobs.py` 的状态表 + 启动回收）。
3. **Docker 产物未验证**。`Dockerfile` / `docker-compose.yml` / `.dockerignore` 是照着
   单进程形态写的，**本机没有 docker，没跑过 build 和 up**。第一次部署要在有 docker 的机器上
   核对：依赖是否全有 wheel（chromadb/pycryptodome/bcrypt/uvloop）、`/health` 是否通、
   日志里"配置加载完成"是否指向挂载进去的 `config.local.yaml`。
4. **备份脚本只覆盖 SQLite**。[scripts/backup_data.py](file:///F:/WWW/AI/AgentCustomService/src/backend/scripts/backup_data.py)
   遇到非 sqlite 的 `database.url` 直接退出。[app/db/session.py:3](file:///F:/WWW/AI/AgentCustomService/src/backend/app/db/session.py#L3)
   写着"切 MySQL 只需改配置并安装 pymysql"，但 `requirements.txt` 里**没有 pymysql**——
   真要走这条路得补依赖、补 `mysqldump` 备份与连接池参数（`pool_size` 分支已备好）。
5. **不用 Alembic**。加列靠 [app/db/migrate.py](file:///F:/WWW/AI/AgentCustomService/src/backend/app/db/migrate.py)
   幂等补列，改列类型/删列/改约束仍然要重建库。字段变动频繁期可接受，长期需要引入真迁移工具。
6. **没有可观测性**。日志是 loguru 按天滚动留 14 天（[app/utils/logging.py:8-16](file:///F:/WWW/AI/AgentCustomService/src/backend/app/utils/logging.py#L8)），
   没有指标、没有回调失败告警。平台/企微回调静默失败只能靠翻日志发现。

## 二、安全暴露面（演示形态 ≠ 生产形态）

1. **admin 权限 ≈ 本机 RCE**。MCP stdio 服务器就是在后端进程旁边拉起子进程。
   现状是双重门禁：`RequireAdmin`（[app/api/v1/mcp.py:53](file:///F:/WWW/AI/AgentCustomService/src/backend/app/api/v1/mcp.py#L53)）
   + `mcp.allowed_commands` 命令名白名单
   （[app/services/mcp/manager.py:33](file:///F:/WWW/AI/AgentCustomService/src/backend/app/services/mcp/manager.py#L33)）。
   **白名单只校验命令名，不校验参数与工作目录**，`python -c "..."` 一样放行。
   生产要么把 admin 收窄到运维账号，要么上容器/独立机器隔离。
2. **待确认卡片对所有登录用户可见**。`GET /api/v1/mcp/pending` 只要求 `CurrentUser`，
   返回里带**完整工具入参 `args`**（[app/services/mcp/confirm.py:56-58](file:///F:/WWW/AI/AgentCustomService/src/backend/app/services/mcp/confirm.py#L56)）——
   订单号、买家标识等会跨用户泄漏。运营台轮询需要它，所以是"有意的放开"，
   但上生产前应改为按会话归属/组过滤。
3. **上传媒体无鉴权**。[app/main.py:77](file:///F:/WWW/AI/AgentCustomService/src/backend/app/main.py#L77)
   把 `data/uploads/media` 静态挂在 `/api/files`，拿到 URL 就能读，没有 token 校验。
   文件名是 uuid 所以不可枚举，但不等于访问控制。
4. **CORS 白名单硬编码** `localhost:8091` / `127.0.0.1:8091`
   （[app/main.py:82](file:///F:/WWW/AI/AgentCustomService/src/backend/app/main.py#L82)）。
   换域名/上生产要么进配置，要么走同源反代（compose 里的注释推荐后者）。
5. **外部回调免 JWT**（企微、四平台），唯一防线是验签。`platforms.<name>.callback_verify`
   可以配成 `"none"` 直接放行——演示方便，生产是漏配即裸奔。真实接入前必须逐平台复核
   口径（见 docs/平台接入.md 的 checklist）。
6. **凭据明文存放**：`config.local.yaml` 里的 api_key / jwt_secret / 企微密钥，以及备份快照
   的同名文件（gitignore 挡住了 `data/`，但快照拷走就等于拷走密钥）；前端 token 存 localStorage。
7. **RBAC 只有 admin/user 两档**，没有客服分级、组、权限位。跨用户读/代答是用户确认过的
   设计决策（一个客服团队共用工作台），真要交付需要 staff 表。
