## 顶层布局

```
AgentCustomService/
├── README.md               # 项目总览与启动指南
├── pyproject.toml          # pytest / ruff / mypy 共用一份配置（口径见"质量闸门"）

├── .dockerignore           # 保证 config.local.yaml（明文密钥）与 data/ 不进镜像层
├── .gitignore
├── docs/                   # 设计文档（本目录）
├── eval/                   # 评测用例与脚本（P6）
└── src/
    ├── backend/            # Python 后端（FastAPI，端口 7861）
    └── frontend/           # Vue3 前端（Vite，端口 8091）
```

技术选型：Python 3.12 + FastAPI + SQLModel + LangChain(OpenAI 兼容) + ChromaDB +
rank_bm25/jieba + tiktoken；Vue 3.4 + TypeScript + Vite 5 + Element Plus + Pinia。
与 AgentChat 保持一致的精简版。

### 分层依赖规则（自上而下，禁止反向 import）

```
api/v1  →  services  →  core / db
              ↓
           (第三方 SDK：langchain、chromadb、httpx…)
```

- `api` 层不写业务逻辑，只做 HTTP 语义（校验、鉴权、状态码、序列化）。
- `services` 可注入 `core/models/manager`，不可 import `api`。
- 表模型全部集中在 `db/models.py`，跨模块共用。
